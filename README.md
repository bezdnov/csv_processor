# Самокритика, недостатки, спорные моменты.
Я не стремился сделать эту программу максимально быстрой. Скорее, я стремился сделать так, чтобы она просто работала при самых разных условиях.
Вот моменты, которые могли бы её ускорить:
1) Фиксированный размер строк и ячеек мог бы помочь быстрее работать со всей структурой в сравнении с постоянной работой на куче (я же стремился больше по памяти оптимизировать)
2) Присутствуют совсем уж простые сравнения для ячеек; можно было бы применить более оптимальные алгоритмы работы со строками (например, XXXXXXXXXXXX)
3) Когда мы запрашиваем у аллокатора чанк на 8 байт, он по факту использует гораздо больше; это ещё один момент, почему по памяти эта программа не настолько хороша

Допускаю, что где-то недоглядел и утечки памяти всё же присутствуют

Предполагается, что названия столбцов не имеют цифр

Всё писалось руками за исключением Makefile и двух помеченных функций
